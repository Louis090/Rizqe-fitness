# تمارين رزقي 🔥

موقع شخصي لتتبع التغذية والتمارين الرياضية.

## المميزات
- 🏠 لوحة رئيسية مع الإحصائيات اليومية
- 🍽️ تتبع الوجبات والسعرات والبروتين
- 💪 برنامج تمارين 5 أيام / يومين راحة
- 📈 متتبع الكتلة العضلية مع مخطط بياني
- 📊 إحصائيات وأهداف يومية محسوبة تلقائياً

## طريقة الرفع على GitHub Pages

1. ارفع الملفات على repository جديد
2. اذهب إلى **Settings → Pages**
3. اختر **Branch: main** والمجلد **/ (root)**
4. احفظ — الموقع سيكون جاهز على: `https://username.github.io/repo-name`

> البيانات تُحفظ محلياً في متصفح كل مستخدم (localStorage)
